# Schaltflächen für AI-Agenten

[English version](readme.md) · [Русская версия](readme_ru.md) · **Deutsche Version**

Schaltflächen eignen sich für kurze, eindeutige und vollständige Antwortmöglichkeiten. Sie verringern Mehrdeutigkeit, vermeiden Tippfehler und verknüpfen die gewählte Option mit einer bestimmten Aktion.

## Telegram

[Anleitung und fertiger Prompt für Telegram](buttons_de.md)

![Schaltflächen in Telegram](telegram_buttons.jpg)

In Telegram werden Schaltflächen an eine Nachricht angehängt und liefern einen eindeutigen Callback zurück. Die Anleitung behandelt sowohl Aktionsbestätigungen als auch neutrale Auswahlmöglichkeiten.

## Codex

[Anleitung und fertiger Prompt für Codex](codex_buttons_de.md)

![Schaltflächen in Codex](codex_buttons.png)

In Codex werden Auswahlmöglichkeiten über die integrierte Abfrage von Benutzereingaben angezeigt. Die Anleitung erklärt, wie dieses Muster in der Benutzerkonfiguration aktiviert wird.
