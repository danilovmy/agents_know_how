# Buttons for AI agents

**English version** · [Русская версия](readme_ru.md) · [Deutsche Version](readme_de.md)

Buttons are useful for short, explicit, and exhaustive answer choices. They reduce ambiguity, prevent typing errors, and bind the selected option to a specific action.

## Telegram

[Instructions and ready-to-use prompt for Telegram](buttons_en.md)

![Buttons in Telegram](telegram_buttons.jpg)

In Telegram, buttons are attached to a message and return an unambiguous callback. The guide covers both action confirmations and neutral choices.

## Codex

[Instructions and ready-to-use prompt for Codex](codex_buttons_en.md)

![Buttons in Codex](codex_buttons.png)

In Codex, choices are displayed through the built-in user-input request. The guide explains how to enable this pattern in the user-level configuration.
